# トドケン — 47都道府県

地図・県庁所在地・名物を、間隔反復で覚えるための個人用アプリ。
iPhone のホーム画面に追加して、アプリのように使えます。

---

## 1. いちばん簡単な入れ方（推奨・5分）

無料・失効なし・オフライン動作。Apple Developer Program も Mac も要りません。

### 手順

1. **このフォルダをそのままWebに置く**
   GitHub の無料アカウントで新しいリポジトリを作り、このフォルダの中身をアップロードする。
   - リポジトリ → `Add file` → `Upload files` → 中身を全部ドラッグ
   - `Settings` → `Pages` → Source を `Deploy from a branch`、Branch を `main` / `/ (root)` にして Save
   - 数十秒後、`https://<ユーザー名>.github.io/<リポジトリ名>/` が公開される
2. **iPhone の Safari でそのURLを開く**（Chrome ではなく **Safari**）
3. 共有ボタン（□に↑）→ **「ホーム画面に追加」**
4. ホーム画面の「トドケン」から起動。以降は機内モードでも動きます。

> なぜ Safari か：iOS で「ホーム画面に追加」とオフライン保存ができるのは Safari だけです。

> 注意：`index.html` をファイルとして直接開くと動きますが、ホーム画面追加とオフライン保存はできません。必ず https のURLから開いてください。

### 更新したいとき

ファイルを差し替えたら `sw.js` の1行目 `const CACHE = "todoken-v1";` の数字を上げてください。
上げないと、iPhone は古いキャッシュを表示し続けます。アプリを一度削除して入れ直すのが確実です。

## 2. Mac がある場合（Xcode・無料Apple ID）

「ホーム画面追加」ではなく、本当のアプリとして入れたい場合。

- Xcode → New Project → **App** → Interface は **Storyboard**、Language は **Swift**
- プロジェクトに `WKWebView` を1つ置き、`loadFileURL` でこのフォルダの `index.html` を読む
- 署名は「Personal Team」（無料のApple ID）で可
- **7日で期限切れ**になります。切れたら Xcode から再ビルド（実質、月に数回の手間）

無料Apple IDの7日制限が煩わしければ、次のどちらか。

| 方法 | 費用 | 有効期間 | 手間 |
|---|---|---|---|
| PWA（このREADMEの1） | 0円 | 無期限 | ほぼゼロ |
| Xcode + 無料Apple ID | 0円 | **7日** | 再ビルドが必要 |
| Apple Developer Program | 年 $99 | 1年 | 年1回更新。TestFlightで家族にも配布可 |

**個人で自分だけが使うなら、PWAが最も合理的です。**

## 3. 学習の仕組み（なぜこの作りか）

| 原則 | 実装 |
|---|---|
| 想起練習 | 4択ではなく、地図を指で当てる。思い出す回数を増やす |
| 即時フィードバック | 誤答時に「押した県の名前」を返す。混同の原因が本人に見える |
| 間隔反復 | 正解すると 1日 → 3日 → 7日 → 16日 → 35日 後に再出題 |
| 即時再学習 | 間違えた県は、そのセッションの3問後にもう一度出る |
| 精緻化 | 全キーワードに「なぜ」を1行。丸暗記を理解に変える |
| 難易度調整 | 覚えていない県は地方ズーム、覚えたら全国表示に自動で切り替わる |
| 記録 | 誤答した県は「まちがいノート」に残り、期限が来たら復習に混ざる |

### 3モード

- **地図** — 県名 → 地図上でタップ。誤答しても2回まで挑戦できる（考えさせるため）。
- **県庁所在地** — 県名と同名の28県／異名の19県を、問題文で区別して出題。異名には語源の一行つき。
- **名物** — 5つの手がかり（産物・名所・文化・食べもの・地理）から県を当てる。答え合わせで全5件の理由が出る。

### 「マスター」の意味

3モードすべてで習熟度が上がった県だけが濃く塗られます。47/47になれば、どの切り口でも出てくる状態です。

## 4. ファイル構成

```
index.html            画面
app.css               見た目
app.js                学習エンジン（間隔反復・出題・記録）
data.js               47都道府県 × 5件（理由つき）
mapdata.js            都道府県のSVGパス
manifest.webmanifest  PWA設定
sw.js                 オフライン用キャッシュ
icon-180.png          ホーム画面アイコン
icon-192.png
icon-512.png
```

フォルダはありません。12個のファイルがすべて同じ階層に並びます。

記録は `localStorage` にのみ保存されます。サーバーもアカウントもありません。

## 5. 内容についての注意

- 特産品・名所・由来は**代表例**です。学習の手がかりとして使い、断言は避けてください。
- 県庁所在地の語源は通説ベースです。
- 地図は国土数値情報（行政区域）を簡略化したものです。出典：国土交通省。
- 修正したい場合は `data.js` の該当行を書き換えるだけです（`w` が理由の一行）。
